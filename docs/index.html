EXPLORING COMPUTER SCIENCE

Course Hub & Repository Docs

Designed for 9th & 10th Grade Math 1 Freshmen | Building Digital Creators

Course Philosophy & Applied AI

This course transitions students from digital consumers to computational builders. Designed specifically alongside Math 1 Algebra standards, students use modern tools without getting bogged down by high-level math theory.

Our AI Approach: "Use, Don't Build (Yet)." Rather than writing complex machine learning models, students leverage generative AI as an everyday coding co-pilot, learn where models physically execute on hardware GPUs, evaluate AI safety/ethics, and train lightweight visual tools like Google Teachable Machine.

6-Unit Curriculum Map

Weeks 1–8

Unit 1: Web Dev & Digital Cogs

HTML5, CSS3 styling, and <div> box models. Students deploy a live GitHub Pages portfolio featuring their custom interactive Digital Cog mascot right away!

Weeks 9–13

Unit 2: PC Hardware & AI Execution

Hardware components (CPU, RAM, Storage, GPU), teardowns, and component specs. Students analyze where AI runs locally versus cloud data centers.

Weeks 14–18

Unit 3: Cyber Safety & Ethics

Password security, phishing detection, spotting AI deepfakes, and safe web practices. Understanding public vs. private GitHub repository controls.

Weeks 19–25

Unit 4: Python Programming Basics

Variables, inputs, logic conditionals (if/else), and math equations. Building text adventure games and terminal pet logic linked to algebra concepts.

Weeks 26–31

Unit 5: Physical Computing

BBC micro:bit hardware, LED displays, sensors, and basic circuits. Linking physical buttons and gesture models via Teachable Machine to hardware actions.

Weeks 32–36

Unit 6: The Cog Ecosystem

Course capstone! Integrating web design, hardware teardown records, Python logic, and micro:bit status into a polished final portfolio showcase.
